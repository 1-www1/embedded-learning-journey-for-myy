## D1 指针本质
**核心一句话**：指针是存"地址"的变量。
```c
int a = 5;
int *p = &a;   // p 存 a 的地址
*p++;          // 先取旧值再自增：先 *(p) 用旧值，再 p 指向下一个
```
**易错**：`*p++` = 先解引用再移动 p；别和 `(*p)++`（让值+1）混淆。

## D2 const
**核心一句话**：左定值，右定向——const 挨着谁锁谁。
```c
const int *p;      // 锁 *p（内容只读），p 可改指向
int *const p = &a; // 锁 p（指向只读），内容可改
```
**易错**：`const int *p` 与 `int const *p` 等价（都锁内容）。

## D3 数组与指针
**核心一句话**：数组名 = 首元素地址；`a[i] == *(a+i)`。
```c
int a[5] = {1,2,3,4,5};
int *p = a;         // p == &a[0]
*p + 1;             // = a[0]的值+1 = 2  （先取值再加）
*(p + 1);           // = a[1] = 2          （先走一格再取值）
```
**易错**：`*p+1`（值+1）vs `*(p+1)`（地址+1格取新值）——括号决定顺序。

## D4 链表遍历
**核心一句话**：每轮 `cur = cur->next` 往后走，直到 NULL。
```c
struct Node { int data; struct Node *next; };
for (struct Node *cur = head; cur != NULL; cur = cur->next)
    printf("%d ", cur->data);
```
**易错**：忘更新 cur → 死循环；不解引用判空 → 野指针。

## D5 Git
**核心一句话**：提交三步 = add → commit → push。
```bash
git add .                # 加入暂存
git commit -m "说明"     # 存档
git push                 # 上传云端
```
**易错**：在错分支提交；commit 信息写清改了什么。

## D6 链表反转
**核心一句话**：三指针 prev/cur/next，**先备份 next 再改 cur->next**（防断链）。
```c
struct Node *prev = NULL, *cur = head;
while (cur != NULL) {
    struct Node *next = cur->next;  // ① 先备份
    cur->next = prev;               // ② 掉头
    prev = cur; cur = next;         // ③ 前移
}
head = prev;   // 新头 = 原链表尾
```
**易错**：不备份 next → 断链，只反转第一个节点。

## D7 字符串安全
**核心一句话**：`strncpy` 限长度 + 手动补 `'\0'`，缺一不可。
```c
char buf[16];
strncpy(buf, text, sizeof(buf) - 1);  // 拷前 15 个
buf[sizeof(buf) - 1] = '\0';          // 手动补结束符
```
**易错**：strncpy 源不够长时不自动补 '\0'；const char* = 函数承诺只读。

## D8-D9 结构体内存对齐
**核心一句话**：成员偏移 = 自身对齐的倍数；总大小 = 最大成员对齐的倍数。
```c
struct A { char c1; int i; char c2; };   // 12 字节（有 padding）
struct B { int i; char c1; char c2; };   // 8 字节（大成员前置省 4B）
#pragma pack(1)                           // 通信帧才用：取消填充保两端一致
struct Frame { uint8_t head; uint16_t len; };
#pragma pack()
```
**易错**：sizeof ≠ 成员和；pack(1) 只用于跨边界数据帧（非对齐变慢/HardFault）。

## D10 位操作
**核心一句话**：置1用`|`、清0用`&~`、翻转用`^`、判断用`&`。
```c
REG |= (1 << 5);        // 置位 bit5
REG &= ~(1 << 5);       // 清零 bit5
REG ^= (1 << 5);        // 翻转 bit5
if (REG & (1 << 5)) {}  // 判断 bit5（用 & 不是 &=，& = 会改寄存器=bug）
```
**易错**：`if (REG &= (1<<5))` 会清掉高 31 位（bug）；读-改-写非原子，中断/多任务会丢更新。
