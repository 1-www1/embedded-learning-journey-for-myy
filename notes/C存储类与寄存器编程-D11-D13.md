## D11 · static 与 extern（存储类）

### 核心框架
- **static = 收**（收作用域进本地 / 拉长生命周期）｜ **extern = 放**（跨文件引用）
- 嵌入式规范：**能 static 就 static**（信息隐藏）

### static 三种语境
```c
// ① 函数内 static：生命周期变程序级，只初始化一次，存数据段(.data/.bss)
void counter(void) {
    static int n = 0;   // 程序启动前初始化一次
    n++;
}

// ② 文件级 static 变量：internal linkage（本 .c 私有）
static int rpm;         // 只有本文件能碰

// ③ static 函数：本 .c 可调用，对外隐藏
static void helper(void) { }
```

### extern：声明 vs 定义
```c
// 判据唯一：是否分配内存
int g_x = 0;          // 定义：分配内存+初始化（只能一次）
extern int g_x;       // 声明：不分配（可无数次）
```

### .c/.h 分工铁律
```c
// xxx.h：只放接口（extern 声明、函数原型、防重复包含）
// xxx.c：定义 + 内部全 static
```
**头文件绝不写定义**（多文件包含 → 重复定义）；**static 绝不放头文件**（每个 .c 一份副本，不同步）。

### 组合拳（static/const/volatile 自由组合）
| 组合 | 含义 | 场景 |
|------|------|------|
| `static const` | 文件私有+只读 | 查表放 Flash |
| `static volatile` | 文件私有+被中断改 | 驱动内部 ISR 标志（标准）|
| `volatile const` | 程序只读+硬件会变 | 只读状态寄存器 |
| `static volatile const uint32_t *p` | 全组合 | 文件私有指针→只读寄存器 |

## D12 · volatile 深挖

### 本质（只解决一件事）
> volatile = 可见性：禁止编译器缓存/合并/删除访问，每次真读真写内存。
> **不解决**：原子性（读-改-写竞争）／跨核乱序（需屏障）。要安全用关中断/互斥锁。

### 四种必加场景
```c
// ① 硬件寄存器 MMIO        ② ISR 共享变量
#define SR (*(volatile uint32_t*)0x40013804)    volatile uint8_t flag;
// ③ 多任务共享             ④ DMA 缓冲区
volatile int shared;                            volatile uint16_t buf[64];
```

### 指针位置辨析（与 const 同读法）
```c
volatile uint32_t *p;       // *左 → 锁内容（常用）
uint32_t * volatile p;      // *右 → 锁指针本身
```

### 编译器优化陷阱
```c
while(status == 0);   // 无 volatile → 编译器缓存 status → 死循环
```

## D13 · 寄存器映射

### 原理三步
```c
// ① 手册寄存器表 → 结构体布局对齐
typedef struct {
    volatile uint32_t CR1;   // 偏移 0x00
    volatile uint32_t SR;    // 偏移 0x04
    volatile uint32_t DR;    // 偏移 0x08
} USART_TypeDef;
// ② 基址强转成结构体指针
#define USART1 ((USART_TypeDef*)0x40013800)
// ③ USART1->SR = 基址 0x40013800 + SR 偏移 0x04 = 0x40013804
```

### 关键细节
- **为什么 volatile**：寄存器被硬件改，禁止缓存
- **为什么 uint32_t**：① 无符号（位操作正确）② 跨编译器保证 32 位
- **成员顺序 = 手册顺序**：错位则布局全乱
- 基址 = 外设基址 + 偏移（芯片头文件已定义，但原理要懂）

### 小而美知识点包（面试拉开差距的点）
```c
// ① __IO = volatile 的马甲（CMSIS）

// ② 地址加 UL：防止有符号化（0x80000000 高位地址必须有 U）
#define BASE 0x40013800UL

// ③ 宏 vs 指针常量：USART1 是宏（每次展开强转），不是变量
// ④ reserved 占位：手册无寄存器区域用数组占位，否则后续偏移全错

// ⑦ uint32_t 保证宽度精确；int 可能 16/32 位
```
